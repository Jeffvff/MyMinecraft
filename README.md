🎮 meuMine

A study project inspired by the early development of Minecraft, built to explore Java, OpenGL, Maven, and game development.

meuMine is a personal project created out of curiosity about how Minecraft was developed in its early days, around 2009.

While studying Java, I became interested in understanding how a game like Minecraft could be built from the ground up. Instead of simply following a tutorial, this project is an opportunity to experiment, research, break things, and learn along the way.

📚 What I'm learning

The main goal of meuMine is to explore technologies and concepts that are new to me:

☕ Java — improving my language and programming skills

📦 Maven — dependency and project management

🖥️ OpenGL — graphics rendering and GPU concepts

🧩 Libraries — learning how external libraries work together

🎮 Game Development — understanding the fundamentals behind a game engine

🧠 Software Architecture — learning how to organize a larger project

🚧 Project Status

This project is currently under development and is primarily focused on learning and experimentation.

Things will probably break.
Things will probably be rewritten.
And that's part of the process. :)

🎯 Goals

The long-term goal is to gradually build a small Minecraft-inspired game while understanding the technologies and concepts behind it.

Some things I may explore along the way:

 Window creation

 OpenGL initialization

 Rendering

 Game loop

 Input handling

 Textures

 Blocks and chunks

 Camera system

 World generation

 Basic physics

 Lighting

 Resource management

This is not intended to be a recreation of Minecraft's source code. It is an independent learning project inspired by the game's early development.

🛠️ Technologies

Java

Maven

OpenGL

Libraries and tools will be added as the project evolves.

💡 Why?

Sometimes the best way to understand something is to build it yourself.

I created meuMine because I wanted to go beyond simply learning Java syntax and actually understand some of the technologies and concepts used to create games.

This project is my way of exploring things I had never worked with before and learning through experimentation.
